### 4. GOLD / MATERIAL LEDGER (CRITICAL)

The business uses a mixed gold model:
- Sometimes gold is provided by the business (deposit to manufacturer)
- Sometimes manufacturer uses their own gold

You MUST ensure system supports:

#### Material Ledger Requirements:
- Track gold deposits to manufacturers
- Track gold consumption per order
- Track returns or adjustments
- Maintain manufacturer-wise running balance

#### Ledger Rules:
- Use transaction-based ledger (no direct balance updates)
- Transaction types:
  - DEPOSIT
  - CONSUMPTION
  - RETURN
  - ADJUSTMENT

#### Each transaction must include:
- manufacturer_id
- order_id (optional)
- weight_grams
- rate_per_gram
- timestamp

#### System Constraints:
- Only ADMIN can:
  - View gold balances
  - Add transactions
- Manufacturers CANNOT see gold balances
- Manufacturers CANNOT enter gold consumption

---

### 5. COGS (Costing System)

Each order must support:

Fields:
- gold_weight_estimated
- gold_weight_actual
- gold_source (SELF / MANUFACTURER)
- making_charges
- cad_cost
- stone_cost

COGS formula:
COGS = (gold_weight_actual × gold_rate) + making_charges + cad_cost + stone_cost

System must:
- Store total_cogs
- Calculate margin = selling_price - total_cogs

---

### 6. System Integrity Rules (IMPORTANT)

- No order can be marked “Completed” without:
  - gold_weight_actual
  - making_charges

- If gold_source = SELF:
  - A CONSUMPTION transaction MUST exist for that order

- Manufacturer gold balance should NEVER silently go negative
  - Must trigger warning or validation
